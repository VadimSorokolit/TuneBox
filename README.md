# TuneBox

* Architecture - **MVVM**
* Networking - **Moya**
* Asynchronous Programming - **Structured Concurrency** `(async/await)`
* Persistence - **SwiftData**
* Dependency Injection - **Resolver**
* Dependency Management **Swift Package Manager**
* Tools - **SwiftLint**
* Unit Testing - **Testing framework**
